Social Media Campaign Performance Analysis

 Objective
Analyze social media campaign performance across Instagram and YouTube to identify high-performing content strategies and audience engagement trends.

Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Dashboard
- Slicers

 KPIs Tracked
- Total Views
- Total Clicks
- Average Engagement Rate
- Content Performance Trends


Dashboard Features
- Interactive slicers for platform and content type filtering
- Dynamic KPI cards
- Trend analysis over time
- Engagement comparison across platforms
- Content performance visualization

 Key Insights
- Reels generated the highest engagement and clicks
- YouTube Shorts contributed strong reach growth
- Static posts showed lower overall performance
- Audience engagement increased steadily over time
